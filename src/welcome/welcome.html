歡迎使用 MarkLens

在瀏覽器裡直接閱讀 Markdown：目錄、摺疊、可排序的表格、Mermaid 圖表，還能直接勾選任務存回檔案。

1允許存取本機檔案

要閱讀電腦裡的 .md，Chrome 需要你手動開啟一個開關（擴充功能無法自行開啟）。

  1. 按下方按鈕開啟 MarkLens 的設定頁
  2. 找到 「允許存取檔案網址」 並開啟
  3. 回到這一頁，狀態會自動更新

檢查中…

2打開一份 Markdown

把任一 .md 檔拖進 Chrome 視窗，或在網址列輸入它的路徑（例如 D:\Projects\README.md）。網路上的 .md 純文字頁面也會自動接管。

建議把 MarkLens 釘選在工具列：按右上角拼圖圖示 → MarkLens 旁的圖釘。點圖示可以調整主題、字體與預設版面。

3常用操作

按鍵功能
t顯示／收合目錄
r原始文字／返回閱讀
w切換文字寬度
d切換主題：自動 → 淺色 → 深色
[ ]全部摺疊／全部展開
  • 表格：拖拉欄寬、點表頭排序、篩選、複製成試算表格式
  • 勾選任務：本機檔案的 - [ ] 可直接點擊存回原檔（第一次會請你授權資料夾）
  • Mermaid 圖表：本機檔案的 ```mermaid 區塊自動繪製
  • 自動更新：用編輯器存檔後，畫面約一秒內更新，保留捲動位置與摺疊

4選用：程式碼區塊中英對齊

程式碼中的中文與 ┌─┐ 罫線表格預設已自動調整寬度；想要最佳效果可安裝免費的 更紗黑體 Sarasa Mono TC，安裝後完全重新啟動 Chrome（網址列輸入 chrome://restart）。
