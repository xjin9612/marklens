## 中文罫線表格

```text
┌──────────┬──────────┬──────────┐
│ 名稱     │ 數量     │ 狀態     │
├──────────┼──────────┼──────────┤
│ 讀書會   │ 128      │ 完成     │
│ 報表     │ 64       │ 進行中   │
└──────────┴──────────┴──────────┘
```

## 英數罫線表格

```text
+----------+----------+----------+
| Name     | Count    | Status   |
+----------+----------+----------+
| order    | 128      | done     |
+----------+----------+----------+
```
