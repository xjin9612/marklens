# 等寬字型與罫線表格

> [!NOTE]
> 預期結果：程式碼區塊內的罫線表格，直線上下對齊、中文與英數混排不錯位。
> 這取決於 Windows 上的等寬字型，請截圖回報。

## 中文罫線表格

```text
┌──────────┬──────────┬──────────┐
│ 名稱     │ 數量     │ 狀態     │
├──────────┼──────────┼──────────┤
│ 訂單卡   │ 128      │ 完成     │
│ 報表     │ 64       │ 進行中   │
└──────────┴──────────┴──────────┘
```

## 英數罫線表格

```text
+----------+----------+----------+
| Name     | Count    | Status   |
+----------+----------+----------+
| order    | 128      | done     |
+----------+----------+----------+
```

## 目錄樹

```text
mdr/
├── manifest.json
├── src/
│   ├── background.js
│   └── content/
│       ├── main.js      進入點
│       └── table.js     表格
└── vendor/
```
