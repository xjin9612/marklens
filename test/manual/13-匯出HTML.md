# 匯出 HTML

> [!NOTE]
> 預期結果：工具列「⤓ 匯出 HTML」下載單一 `.html` 檔，用瀏覽器開啟後外觀與閱讀頁一致。

## 步驟

1. 先按 ▸ 全部摺疊，再勾選下方第一個任務
2. 按工具列「⤓ 匯出 HTML」→ 底部出現「已匯出 13-匯出HTML.html」，檔案在下載資料夾
3. 用 Chrome 開啟下載的檔案

## 檢查項目

- [ ] 匯出的頁面所有段落都是展開的，沒有摺疊按鈕、`#` 錨點與表格工具列
- [ ] 下方的 Mermaid 圖、公式、程式碼高亮、表格都正常顯示
- [ ] 勾選狀態與匯出時相同（勾選框為灰色、不可點）
- [ ] 主題與匯出時相同（深色匯出就是深色）
- [ ] 把 html 檔複製到別的資料夾再開，圖片仍顯示
- [ ] 選測：F12 → Console 沒有錯誤；Sources 裡看不到任何 JavaScript
