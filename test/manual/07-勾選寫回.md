# 勾選寫回

> [!NOTE]
> 預期結果：點下面的勾選框，原檔立即更新；第一次會引導你授權資料夾。

## 步驟

1. 點「第一項」的勾選框 → 底部出現「此檔案所在的資料夾尚未授權寫回」→ 按「授權資料夾」
2. 在授權頁按「＋ 新增資料夾」，選這個 repo 的資料夾（`marklens`）或它的上層→ 按「返回原分頁」
3. 再點一次「第一項」→ 出現「已勾選並存檔」
4. 按「原始文字」確認 `- [x] 第一項`，再按「返回閱讀」
5. 點「第二項」取消勾選 → 按提示上的「復原」
6. 用編輯器在本檔最後加一行 `- [ ] 新項目` 但**先不要**讓頁面自動更新（立刻）點「巢狀任務」→ 若出現「檔案已在其他地方修改」屬正常，畫面會重新載入，再點一次即可
7. 重開 Chrome 後再點任一勾選框 → 若出現「需要重新確認存取權限」→「前往確認」→ 在權限詢問選「每次造訪時允許」
