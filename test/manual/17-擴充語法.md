# 擴充語法

> [!NOTE]
> 預期結果：下面的容器區塊顯示成提示框，`details` 可以摺疊，最後的定義清單術語是粗體、說明縮排。

## 測試清單

- [ ] 「提示」「自訂標題」「危險」「方括號標題」四個提示框的顏色分別是綠、黃、紅、藍
- [ ] 「點我展開」預設收合，點擊後展開
- [ ] `::: unknown` 那一段照原文顯示三個冒號
- [ ] 切到深色主題，提示框與定義清單的顏色正常
- [ ] Obsidian 語法：開啟 `test/fixtures/obsidian.md`，`[[…]]` 都是連結，`[[#本頁標題]]` 點了跳到「本頁標題」；「可以收合嗎？」預設收合、「預設展開」預設展開，點標題可切換；`> [!bug] 自訂 **標題**` 是紅色提示框、標題有粗體
- [ ] 匯出 Word 後，可摺疊的提示框以一般提示框呈現，內容完整

## 範例

::: tip
VitePress 的提示，沒有標題時顯示預設的「Tip」。
:::

::: warning 自訂標題
內容可以有 **粗體** 與清單：

- 第一項
:::

:::danger
Docusaurus 寫法，冒號後不空格。
:::

:::note[方括號標題]
Docusaurus 的方括號標題。
:::

::: details 點我展開
摺疊的內容
:::

::: unknown
未知的容器保留原文。
:::

術語一
: 第一個說明

術語二
: 第二個說明
: 另一個說明
