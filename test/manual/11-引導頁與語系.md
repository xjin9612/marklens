# 引導頁與介面語系

> [!NOTE]
> 預期結果：引導頁正確顯示檔案存取狀態；介面文字依瀏覽器語言顯示繁中或英文。

## 引導頁

首次安裝才會自動開啟。已經裝過的話，從 popup 按「使用說明」開啟。

- [ ] 第 1 步顯示綠色「✔ 已開啟，可以閱讀本機檔案」，且「開啟擴充功能設定」按鈕已隱藏
- [ ] 到擴充功能「詳細資料」暫時關閉「允許存取檔案網址」，切回引導頁 → 變成「尚未開啟」並出現按鈕；測完記得打開
- [ ] 頁尾版本號為目前版本，GitHub 與更新紀錄連結可開啟

## 介面語系

預設跟隨 Chrome 的語言（中文顯示繁中，其他語言顯示英文），也可以在 popup 指定。

- [ ] 工具列有「⤓ 匯出 HTML」與「◐ 主題：自動」
- [ ] popup →「外觀」→「介面語言」選 **English** → popup 立即變成英文
- [ ] 重新整理本頁 → 工具列、目錄搜尋框、表格按鈕都變成英文；從 popup 按 Help 開的引導頁也是英文
- [ ] 改回「跟隨瀏覽器」並重新整理 → 恢復繁體中文
- [ ] 註：`chrome://extensions` 上的擴充功能說明與快捷鍵名稱仍跟隨 Chrome 語言，這是 Chrome 的限制
