## 外部連結

- [ ] 點 [GitHub](https://github.com/xjin9612/markloupe) → 在**新分頁**開啟，本頁留著
- [ ] 點 [00-說明.md](./00-說明.md)（相對路徑）→ 在**目前分頁**開啟
- [ ] 頁內跳轉不開新分頁：滑鼠移到任一標題，文字右邊會出現淡淡的 `#`，點它 → 網址結尾多出 `#標題`、畫面捲到該處，仍在本分頁；用選單鈕打開目錄點任一項也一樣
- [ ] popup →「版面預設值」取消「外部連結在新分頁開啟」，重新整理後 GitHub 連結改在目前分頁開啟；測完勾回來
