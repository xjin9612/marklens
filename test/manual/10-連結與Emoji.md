# 外部連結與 Emoji

> [!NOTE]
> 預期結果：外部連結開新分頁、Emoji 短碼轉成圖示，檔名不會變成連結。

## 外部連結

- [ ] 點 [GitHub](https://github.com/xjin9612/markloupe) → 在**新分頁**開啟，本頁留著
- [ ] 點 [00-說明.md](./00-說明.md)（相對路徑）→ 在**目前分頁**開啟
- [ ] 頁內跳轉不開新分頁：滑鼠移到任一標題，文字右邊會出現淡淡的 `#`，點它 → 網址結尾多出 `#標題`、畫面捲到該處，仍在本分頁；用選單鈕打開目錄點任一項也一樣
- [ ] popup →「版面預設值」取消「外部連結在新分頁開啟」，重新整理後 GitHub 連結改在目前分頁開啟；測完勾回來

## 失效的相對連結

[存在的檔案](./00-說明.md)、[不存在的檔案](./沒有這個檔案.md)、[不存在的資料夾](./沒有這個資料夾/a.md)、[存在的資料夾](./子資料夾/)

- [ ] 「不存在的檔案」「不存在的資料夾」有紅色波浪底線，滑過顯示「找不到這個檔案」；另外兩個沒有
- [ ] 在同資料夾建立「沒有這個檔案.md」後，隨意修改本檔存檔，該連結的波浪底線消失；測完刪除
- [ ] popup →「版面預設值」取消「標出指向不存在本機檔案的連結」，重新整理後沒有波浪底線；測完勾回來
