# 側邊欄：目錄與檔案

> [!NOTE]
> 預期結果：側邊欄頂端為「選單 ｜ 目錄 檔案 ｜ 搜尋」，檔案分頁列出本資料夾的 Markdown 與子資料夾。

## 目錄分頁

- [ ] 頂端左邊是 ☰，按它收合側邊欄；收合後工具列左上角的 ☰ 在**同一個位置**，再按一次展開
- [ ] 按 🔍 或在頁面上按 `/` → 搜尋框出現，輸入「分頁」只剩含「分頁」的標題；按 Esc 關閉並恢復

## 檔案分頁

- [ ] 點「檔案」→ 上方顯示「manual · N 份」，資料夾（子資料夾）排在前面，接著 00～15 依編號排序，本檔標亮
- [ ] 點「▸ 子資料夾」→ 展開看到「更深一層」與「範例.md」；再點「更深一層」→ 看到「深層.md」
- [ ] 點「深層.md」→ 在本分頁開啟；檔案分頁頂端仍是「manual」，樹展開到「深層.md」並標亮，可直接點回 15-側邊欄.md
- [ ] 另開新分頁直接打開 `子資料夾/範例.md`，切到檔案分頁 → 頂端是「子資料夾」，按「上一層」箭頭回到 manual，「子資料夾」維持展開
- [ ] 連按幾次「↑」到上層，在「marklens」上按右鍵 →「以此資料夾為起點」→ 起點切回 marklens；再展開 test、對「manual」按右鍵切回來
- [ ] 在檔案分頁連續點幾份不同的檔案：畫面直接換成新檔，中間沒有整頁空白，側邊欄不閃「讀取中」
- [ ] 在「檔案」分頁按 `/` 輸入「深」→ 只列出「子資料夾/更深一層 / 深層.md」
- [ ] popup →「檔案列表」→「略過的名稱」加上 `, 子資料夾`，重新整理 → 檔案分頁不再顯示「子資料夾」；測完刪掉

## 用編輯器開啟

- [ ] 預設工具列沒有「編輯」
- [ ] popup →「編輯器」選 VS Code，重新整理 → 工具列出現「編輯」
- [ ] 在目錄點「檔案分頁」，再按「編輯」→ Chrome 詢問是否開啟 Visual Studio Code，允許後 VS Code 開啟本檔並跳到「## 檔案分頁」那一行
- [ ] 改選「自訂網址…」填 `https://example.com/{path}` → popup 提示網址不合法、工具列不顯示按鈕；測完改回「不使用」或 VS Code

## 其他

- [ ] 窄視窗（寬度小於 900px）：☰ 打開抽屜式側邊欄，點空白處關閉
- [ ] 從 popup 按「使用說明」開引導頁，頁尾有黑色 GitHub 圖示（滑鼠移上去變藍），點它開啟專案頁
