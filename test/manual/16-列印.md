# 列印與存成 PDF

> [!NOTE]
> 預期結果：工具列「列印／PDF」印出整份文件：摺疊的段落與篩選掉的表格列都會印出，深色主題改用淺色，頁首頁尾只有頁碼。

## 步驟

1. 工具列「主題」選「深色」
2. 在下方「表格」的篩選框輸入 `ap`（只剩 2 列），再按工具列「全部摺疊」
3. 按工具列「列印／PDF」，目的地選「另存為 PDF」
4. 關閉列印對話框

## 檢查項目

- [ ] 預覽是淺色的，Mermaid 圖也是淺色（不是深色的方塊）
- [ ] 所有段落都展開了，沒有摺疊按鈕、`#` 錨點、工具列與側邊欄
- [ ] 表格的 6 列都印出來，表頭與每一格都有框線
- [ ] 頁首沒有日期與標題，頁尾沒有檔案路徑，只在下方中間印「1 / 2」這樣的頁碼
- [ ] 關閉對話框後畫面回到深色，摺疊與篩選維持原樣
- [ ] 用 Ctrl+P 再印一次：一樣是淺色、全部展開（Mermaid 圖可能仍是深色，這是已知限制）
- [ ] 測完把主題改回原本的設定
