# MarkLens 實機測試

在 Chrome 開啟本資料夾的 `.md` 檔逐一檢查。每份檔案開頭都有「預期結果」。

開始前：

0. 本資料夾的檔案測試時會被勾選寫回修改，測完執行 `git restore test/manual` 還原

1. `chrome://extensions` → MarkLens → 按重新載入圖示，**再重新整理已開的 .md 分頁**
2. 確認 MarkLens「詳細資料」中「允許存取檔案網址」已開啟
3. 工具列上的 MarkLens 圖示應為新版（靛藍底、青色對焦框中的 M）
4. 側邊欄切到「檔案」分頁即可在測試檔之間切換；左上角的選單鈕顯示或收合側邊欄

## 17. 擴充功能重新載入

1. 開著任一個 .md 分頁
2. 到 `chrome://extensions` 按 MarkLens 的重新載入
3. 回到 .md 分頁捲動幾下

- [ ] 工具列左側出現「擴充功能已更新，重新整理後套用」
- [ ] 擴充功能頁的「錯誤」不再新增 `Extension context invalidated`
