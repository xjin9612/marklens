1. 下面表格：點「數量」排序一次、拖拉「說明」欄寬、滑過表格在篩選框輸入「a」
2. 摺疊「## 摺疊這段」
3. 用 VS Code 或記事本開啟本檔，把下面的「計數：1」改成「計數：2」並存檔

3. 按工具列的「N 處改動」幾次
4. 把「計數」改回 2 並存檔
