# 18. 複製與網站權限

## 預期結果

自動測試涵蓋剪貼簿的內容與行號。這裡檢查無法自動化的部分：貼到其他程式的格式、Chrome 的權限對話框。

## 複製內容

1. 按工具列的「複製」→「複製內容（Markdown）」
2. 分別貼到 Word（或 Outlook）與記事本

- [ ] Word 保留標題、粗體、清單、表格與程式碼區塊
- [ ] 記事本是 Markdown 原文
- [ ] 貼上的內容沒有摺疊按鈕、`#` 錨點、複製按鈕等閱讀介面元件

## 複製位置

1. 滑到下方「範例章節」標題，按標題旁的複製按鈕 →「複製位置（路徑與行號）」
2. 貼到記事本

- [ ] 內容為 `D:\…\18-複製與網站權限.md:起-迄 (範例章節)` 這種 Windows 路徑，行號與編輯器中的行號相同
- [ ] 選取下方段落的一部分，出現「複製原文」與「複製位置」，複製位置的行號是那個段落的行號
- [ ] 按 `r` 切到原始文字，左側有行號；點行號，提示顯示該行的位置

### 範例章節

這一段用來選取並複製位置。

## 網站權限

1. 在 `chrome://extensions` 移除 Markloupe，再載入一次
2. 開啟網路上的 `.md`，例如 <https://raw.githubusercontent.com/xjin9612/markloupe/main/README.md>

- [ ] 安裝時沒有「讀取及變更所有網站上的資料」的警告
- [ ] 引導頁有「也在網頁上的 .md 檔案啟用」選項
- [ ] 尚未開啟時，網路上的 `.md` 顯示為純文字
- [ ] 在 popup 勾選後，Chrome 詢問網站存取權；同意後重新整理頁面，Markloupe 接管
- [ ] 拒絕時勾選框回到未勾選
- [ ] 在 popup 取消勾選，重新整理後回到純文字
- [ ] 在擴充功能「詳細資料」移除網站存取權後，popup 的勾選框同步變成未勾選
